ADG(B) RAW DATA V15.5 — SUBROWS

NEW
- Every MAIN Raw Data row has a "+ Subrow" button.
- Only Head Office can add a subrow.
- Head Office security code is required.
- The subrow appears immediately below its parent row.
- Each subrow has:
  O/o ADG(B), CE(B), CE(HAL), SE&PD, SE(Mysore), SE(Hubli), TOTAL.
- Each subrow has its own Edit button.
- Existing rows and values are preserved.
- Existing main-row totals and subrow totals are calculated automatically.

2. Save.
3. Do NOT run setupPortal().
4. Do NOT run setPortalSecurityCodes().
