ADG(B) REPORT PORTAL V15.33 — AUTO-UPDATING DATE

NEW
- Adds today's date to the top header row.
- Format example: 28th-Aug-2026 (Friday)
- Uses browser local date.
- Automatically rechecks every minute, so it changes after midnight without refresh.
- Unique pink/magenta/lilac highlight so the date is easy to spot.
- Compact pill design to preserve header height.

INSTALL
1. Replace raw-data.js.
2. Replace sticky-notes.js.
3. Use:
   <script src="raw-data.js?v=15.33"></script>
   <script src="sticky-notes.js?v=15.33"></script>
4. Commit and hard refresh.

Code.gs V15.33 is included only for matching BE v15.33.
Do NOT run setupPortal() or setPortalSecurityCodes().
