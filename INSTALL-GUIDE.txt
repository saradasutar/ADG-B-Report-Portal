ADG(B) REPORT PORTAL V16.2 — NO WORKFLOW DETAILS / SUPERFAST

WHAT WAS REVERTED
- Workflow Details button removed.
- Workflow side drawer removed.
- Review / Accept / Return controls removed.
- Receipt / version-history / activity-timeline UI removed.
- No submissionOverview request.
- No submissionDetails request.
- No reviewSubmission request.
- Upload returns to the earlier simple behaviour:
  Upload -> Submitted -> View / Replace / Remove.

WHAT IS KEPT FROM V16.1
- 180-second bootstrap cache with automatic write invalidation.
- Lazy Target / Reminder loading.
- No Sticky backend request merely because the user signs in.
- No automatic PDF iframe loading.
- Compact two-row dashboard.
- Date + live time in top row.
- Single FE / BE version display inside dashboard.
- Distinct colours/highlights.
- Larger/bolder text.
- Current files / Users / Sign out.
- All existing login permissions and security.
- Raw Data feature.

IMPORTANT
If V16.0/V16.1 already created extra workflow columns or a
Submission_Activity sheet, V16.2 leaves them untouched but does NOT use them.
This protects existing data and avoids unnecessary migration work.

INSTALL
GITHUB:
1. Replace raw-data.js.
2. Replace sticky-notes.js.
3. Use:
   <script src="raw-data.js?v=16.2"></script>
   <script src="sticky-notes.js?v=16.2"></script>
4. Commit and hard refresh once.

APPS SCRIPT:
1. Replace Code.gs.
2. Save.
3. Deploy > Manage deployments > Edit > New version > Deploy.
4. Do NOT run setupPortal().
5. Do NOT run setPortalSecurityCodes().

FE v16.2 | BE v16.2
