ADG(B) PORTAL V15.7 — ADMIN-CONTROLLED TARGET / REMINDER STICKY NOTES

NEW TARGET / REMINDER FEATURE
- Floating 🎯 Target / Reminder button; panel is collapsed by default.
- Everyone can view active and completed reminders.
- Only Head Office admin can change anything.
- Admin unlock uses the EXISTING Head Office security code.
- Add sticky note.
- Six colour choices: yellow, pink, blue, green, orange, purple.
- Small ✎ Edit and 🗑 Delete buttons.
- ✓ Completed moves the sticky note out of Active and saves it in Completed history.
- Completed notes can be restored by admin.
- 📌 Pin keeps selected notes above others.
- Pinned notes can still be collapsed/expanded by clicking their header.
- Drag sticky notes to move/reorder them.
- ↑ and ↓ buttons are also provided for easy movement.
- − Size / ＋ Size changes Small / Medium / Large.
- Size, colour, pin, collapse state and order are saved in Google Sheets.
- Sticky data is stored automatically in a new Sticky_Notes sheet.
- Existing reports, Raw Data, subrows and security codes are preserved.

ADMIN CONTROL
- The Target / Reminder panel opens in View mode.
- Click 🔒 Admin inside the panel.
- Enter the existing Head Office security code.
- Admin controls become visible.
- The code is retained only for the current browser-tab session.
- Every backend write still verifies the Head Office code.

APPS SCRIPT
1. Replace the complete current Code.gs with Code.gs from this package.
2. Save.
3. DO NOT run setupPortal().
4. DO NOT run setPortalSecurityCodes().
5. Deploy > Manage deployments > Edit > New version.
6. Execute as: Me.
7. Who has access: Anyone.
8. Deploy.

GITHUB
1. Replace raw-data.js with the supplied raw-data.js.
2. Upload sticky-notes.js beside index.html and raw-data.js.
3. Immediately before </body> in index.html use:
   <script src="raw-data.js?v=15.7"></script>
   <script src="sticky-notes.js?v=15.7"></script>
4. Commit.
5. Hard-refresh with Command + Shift + R.
