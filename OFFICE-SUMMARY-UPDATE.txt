ADG(B) PORTAL — OFFICE-WISE SUBMISSION SUMMARY

This update changes only the GitHub Pages frontend.

1. Open the ADG-B-Report-Portal repository on GitHub.
2. Open the existing index.html file and choose Edit.
3. Replace its complete contents with the supplied index.html.
4. Commit the change.
5. Wait 2–3 minutes, then refresh the portal with Ctrl+Shift+R.

No Apps Script or Google Drive change is required.

The Current submission cycle card will show each office as Submitted / Total,
for example CE(B) 3/5. Counts update automatically from the submission matrix.
