# ADG(B) Report Submission Portal

A lightweight report-submission system for O/o Additional Director General (B), CPWD, Bengaluru.

## Included files

- `index.html` — responsive GitHub Pages frontend
- `Code.gs` — Google Apps Script backend
- `DEPLOYMENT-GUIDE.md` — step-by-step instructions for a non-coder

## Offices

- CE(HAL)
