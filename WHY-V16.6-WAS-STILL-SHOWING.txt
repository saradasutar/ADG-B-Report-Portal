DIAGNOSIS

The GitHub repository contains the newer V16.8 source, but the screenshot
still showed FE v16.6. This means the browser/GitHub Pages delivery path was
still serving an older cached JavaScript asset.

Changing only a query string such as:
raw-data.js?v=16.8

can still leave room for stale browser/CDN behaviour in some environments.

V16.9 changes the PHYSICAL file names:
portal-v169.js
sticky-v169.js
adgb-v169.svg

Therefore an older cached V16.6 file cannot satisfy the new request.

The one-time cache reset additionally removes any old repository service-worker
and Cache Storage entries.
